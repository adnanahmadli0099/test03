# Responsive Business Website Demo

A multi-page static website built with HTML, CSS and vanilla JavaScript. It requires no build step.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services / Products
- `gallery.html` — Gallery with accessible image modal
- `reviews.html` — Review information (no fabricated reviews)
- `faq.html` — FAQs
- `contact.html` — Contact details and validated demo enquiry form

## Run locally
Open `index.html` in a browser, or use a local static server such as VS Code Live Server.

## Configure the business
Edit `assets/js/config.js` first:
- Business name and category
- Verified phone number, email, address and opening hours
- WhatsApp number
- Google Maps and review URLs
- Social media URLs

Then edit the placeholder copy in the HTML files and replace stock images with approved business photographs or licensed images.

## Important
- The business identity and profile details were not verified when this demo was generated.
- The contact form only validates input locally; it does not send messages. Connect a backend or form provider before launch.
- Phone, WhatsApp, reviews and social links require real verified details.
- Do not publish placeholder claims, fictional reviews, invented ratings, or unverified contact details.
- External Unsplash image URLs are used as visual demo assets; confirm licensing and availability for the final deployment.
- This is a static website and does not require a package installation.
